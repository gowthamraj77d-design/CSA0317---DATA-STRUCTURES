🎓 DATA STRUCTURES USED IN LIFEOS Academic Overview
📋
QUEUE
Task Scheduling

Organizes tasks in FIFO processing order. Newest items enqueue at rear, head task dequeued upon completion.

FIFO · First In, First Out
🎯
TREE
Goal Management

Organizes main goals and sub-goals hierarchically. Child completion automatically recalculates parent goal progress.

N-ary Tree · Recursion
🕒
STACK
Activity History

Logs recent user actions in LIFO order. The most recent activity is pushed to top and displayed first.

LIFO · Last In, First Out
🔍
HASH MAP
Universal Search

Indexes all tasks, goals, notes, and activity events by unique keys for fast O(1) retrieval and filtering.

HashMap · O(1) Retrieval
